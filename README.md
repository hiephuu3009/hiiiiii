# Website giới thiệu cá nhân và CV trực tuyến

## 1. Giới thiệu

Đây là dự án xây dựng website giới thiệu cá nhân và CV trực tuyến.

Website cung cấp thông tin về:

- Thông tin cá nhân
- Giới thiệu bản thân
- Học vấn
- Kỹ năng
- Dự án
- CV
- Thông tin liên hệ

## 2. Công nghệ sử dụng

- HTML5
- CSS3
- JavaScript
- Google Fonts
- GitHub Pages

## 3. Chức năng

### Trang chủ
Hiển thị tên, nghề nghiệp, giới thiệu ngắn và các liên kết.

### Giới thiệu
Hiển thị thông tin cá nhân và định hướng nghề nghiệp.

### Học vấn
Hiển thị quá trình học tập.

### Kỹ năng
Hiển thị các kỹ năng lập trình và mức độ thành thạo.

### Dự án
Hiển thị các dự án đã thực hiện.

### CV
Hiển thị thông tin CV trực tuyến và cho phép tải CV.

### Liên hệ
Cho phép người dùng nhập thông tin và nội dung liên hệ.

### Dark Mode
Cho phép chuyển đổi giữa giao diện sáng và tối.

### Responsive
Website có khả năng hiển thị trên máy tính, máy tính bảng và điện thoại.
